# Answer template

Fill this in the user's language. Delete any line that would be padding.

```markdown
**<The answer in one or two sentences.>**

Why it holds: <challenge 1> was <what the evidence showed> (`<path:line or URL>`).
<Challenge 2> changed the recommendation from <old> to <new> because <evidence>.

Assuming: <assumption> - if wrong, <what breaks>. <Second assumption, same shape.>

This flips if <the one fact that would change the answer>. Full log: `GRILL.md`.
```

## Checks before sending

- First line answers the question; no preamble, no "great question".
- At most three challenges named; the rest live in `GRILL.md`.
- Every assumption has a consequence attached.
- Ends with the flip condition, not with a question.
- Under ~300 words unless depth was requested.
