# คำทำนายที่สกิลนี้มี

ตารางนี้มีคำทำนายสำหรับเลขที่พบบ่อยและเลขในตัวอย่างของสกิล — **ไม่ใช่ตาราง 1–109 ครบชุด**
ถ้าเลขที่ได้ไม่อยู่ในตาราง ให้บอกเลขนั้นและชี้ไปที่ตารางอ้างอิงท้ายไฟล์ ห้ามแต่งคำทำนายเอง

| เลข | ผล | ความหมายย่อ |
|---:|---|---|
| 1 | ให้คุณ | ดาวอาทิตย์ — ความเชื่อมั่น ผู้นำ เด่นในสังคม แต่ระวังความหยิ่งทะนง |
| 2 | ปานกลาง | ดาวจันทร์ — จินตนาการ อ่อนโยน มีเสน่ห์ แต่ใจหวั่นไหวและตัดสินใจยาก |
| 3 | ปานกลาง | ดาวอังคาร — กล้าหาญ เด็ดเดี่ยว ชอบแข่งขัน แต่ระวังใจร้อนและอุบัติเหตุ |
| 4 | ให้คุณ | ดาวพุธ — สติปัญญา ปฏิภาณ เจรจาเก่ง เอาตัวรอดด้วยปัญญา |
| 5 | ให้คุณ | ดาวพฤหัสบดี — คุณธรรม ปัญญา ผู้ใหญ่อุปถัมภ์ ชีวิตมั่นคง |
| 6 | ให้คุณ | ดาวศุกร์ — ศิลปะ รสนิยม การเงิน ความรัก มีคนช่วยเหลือ |
| 7 | ให้โทษ | ดาวเสาร์ — อดทน ฝ่าอุปสรรค เหนื่อยก่อนสำเร็จ |
| 8 | ให้โทษ | ดาวราหู — พลิกแพลง กล้าเสี่ยง ระวังมัวเมาและอบายมุข |
| 9 | ให้คุณ | ดาวเกตุ — ลางสังหรณ์ ต่างประเทศ เรื่องลี้ลับ แคล้วคลาด |
| 11 | ให้โทษ | ความขัดแย้งในตัวเอง ดื้อรั้น ซ่อนความแข็งกร้าวใต้บุคลิกอ่อนโยน ชีวิตดิ้นรน |
| 14 | ให้คุณ | สติปัญญาและมงคล ฉลาด มีตำแหน่งก้าวไกล ผู้คนเคารพ รักความยุติธรรม สำเร็จมาก |
| 51 | ให้คุณ | รักความสมบูรณ์แบบ ปัญญาดี ผู้ใหญ่อำนวยโชค ระวังเข้มงวดจนตึงเครียด |
| 65 | ให้คุณ | คู่ทรัพย์คู่โชค ราบรื่น ผู้ใหญ่สนับสนุน หาเงินเก่ง ความรักมั่นคง |

## อ่านอย่างไร

- **เลขหลัก** คือผลรวมเต็มของชื่อ, นามสกุล และผลรวมทั้งสอง — อ่านสามตัวนี้ก่อน
- **เลขทอน** คือผลรวมที่บวกหลักซ้ำ เช่น `65 → 6+5=11 → 1+1=2`; เป็นเพียงแรงประกอบ
- ถ้าเลขหลักเป็น “ให้คุณ” แต่เลขทอนเป็น “ให้โทษ” ให้บอกตามจริงทั้งสองชั้น ไม่ต้องสรุปว่าชื่อเสีย
- เลข 11/22/33 บางสำนักหยุดไว้เป็นเลขพิเศษ; สกิลนี้แสดงทั้งเลขทอนและเลขสุดท้ายเพื่อให้เทียบได้
